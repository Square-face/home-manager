# Dotfiles

This is my home manager configuration. I package most of the programs here,
instead of in the [system config](https://git.sq8.dev/system-conf.git), makes
it more portable.

I dont use any helpers to structure my config appart from standard nix flakes
and home-manager. This is partialy because im still learning nix(OS) and not
something that only applies to a subset of it, but i'm also experimenting with
a minimalist approach, so i try to keep as few dependencies around as possible.

Feel free to use this repo as inspiration/refrence for any of you own
home-manager adventures.
